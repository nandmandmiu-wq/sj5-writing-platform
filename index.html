聖若瑟教區中學第五校作文數據分析平台

多班級・多次作文・三文體・完整句庫・自動評語・班級統計・總覽分析

現在資料層級：年級 → 班級 → 作文次數。

匯入學生名單

可直接貼 Excel 兩欄資料：學號、姓名。每行一位，例如：
1　陳梓晞
2　鄭智中

匯入後仍可逐位修改文體、等級與評語。

匯入成績／評級資料

可直接貼 Excel 表格，或上傳 Excel / CSV 檔。建議欄位： 學號、姓名、文體、內容等級、內容句號、語言等級、語言句號、結構等級、結構句號、文面等級、文面句號、技巧等級、技巧句號。
可只填等級（如 3 或 3級），也可只填各項分數（如內容分、語言分、結構分、文面分、技巧分），系統會自動換算至最接近等級；文體可留空，之後用全班文體套用。

如上傳 .xlsx，需要有網絡載入 SheetJS；若無法讀取，可直接從 Excel 複製貼上。

使用說明

  1. 先選擇年級、班級及作文次數；每一個組合都是獨立評改頁。
  2. 如果要新增第6次、第7次作文，可按「新增作文次數」。
  3. 可以用「匯入名單」一次貼入全班學號和姓名；也可用「匯入成績」貼入或上傳 Excel / CSV 成績表。
  4. 每頁都有即時統計：人數、平均分、最高最低分、最弱項目。
  5. 「全級／全校總覽」可選「多次整合」或「按作文次數」查看，並提供棒形圖、趨勢圖及標準化雷達圖。
  6. 資料目前儲存在使用者本機瀏覽器；不同電腦、不同老師之間不會自動同步。
多位老師同步方案：
GitHub Pages 是靜態網站，本身不能共同儲存資料。本版已加入 Google Apps Script 同步入口。教師可把資料上傳到同一個 Google Sheet 後台，其他老師再下載同步。
